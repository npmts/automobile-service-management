# automobile-service-management

This repository contains a basic [NestJS](https://nestjs.com/) project. It requires **Node.js 22** to run. Use `nvm` or your preferred version manager to ensure Node 22 is active.

## Scripts

- `npm run start` - start the application
- `npm run start:dev` - start in watch mode for development
- `npm run build` - compile the TypeScript sources
